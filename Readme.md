## ⚙️ 4. Funcionamento do projeto

O portfólio possui uma barra de navegação que permite acessar as seguintes seções:

- 👤 **Perfil:** apresentação pessoal.
- 📂 **Projetos:** apresentação dos projetos desenvolvidos.
- 📧 **Contato:** informações para contato e oportunidades profissionais.

O site utiliza o Bootstrap para organizar os elementos e facilitar a navegação em diferentes tamanhos de tela.

## ✨ 5. Recurso novo adicionado

O recurso novo adicionado ao projeto foi um **carrossel de projetos**.

Esse recurso permite apresentar diferentes imagens de projetos em uma sequência de slides, utilizando botões de navegação para avançar e retornar.

## 🔧 6. Como o recurso foi implementado

O carrossel foi implementado utilizando o componente Carousel do Bootstrap 5.3.3.

Foram utilizados:

- 🎠 `carousel`: estrutura principal do carrossel.
- 📑 `carousel-inner`: organização dos slides.
- 🖼️ `carousel-item`: conteúdo de cada slide.
- ◀️ `carousel-control-prev`: botão para voltar.
- ▶️ `carousel-control-next`: botão para avançar.

Também foi utilizado o JavaScript do Bootstrap para permitir a navegação entre os slides.
